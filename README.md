# Cekedis

Pasar barang second yang mesra pengguna — jual dan cari barang terpakai dari jiran ke jiran.

## Ciri-ciri

- Carian dan penapis kategori barang
- Kad senarai barang bergaya "tag harga"
- Halaman butiran barang dengan maklumat penjual
- Borang "Jual Barang" untuk menyiarkan barang baru
- Reka bentuk responsif untuk mudah alih dan desktop

## Menjalankan projek

Projek ini ialah satu fail HTML statik (`index.html`) — tiada proses binaan diperlukan.

1. Muat turun atau clone repo ini
2. Buka `index.html` terus di pelayar

Atau layari terus melalui GitHub Pages selepas diaktifkan (lihat bawah).

## Deploy ke GitHub Pages (percuma)

1. Pergi ke **Settings → Pages** dalam repo ini
2. Di bawah "Build and deployment", pilih source: **Deploy from a branch**
3. Pilih branch `main` dan folder `/ (root)`
4. Simpan — laman akan tersedia di `https://<username>.github.io/<nama-repo>/` dalam beberapa minit
